PEBBLE LUNCHAR

              
Minecraft 离线启动器 · Lite（Rust + WebView2）

              

              

                
                
              

              

                这一版换掉了运行时。上一版基于 Electron，必须自带一整套 Chromium
                （解包 172 MB，压完仍有 60 MB 打底）；现在界面跑在 Windows 自带的 WebView2 里，
                程序本体只有一个几 MB 的 exe。

                功能范围：离线启动 · 本地版本扫描 · Java 检测 · 内存与分辨率 · 运行日志。

                不含：版本下载与加载器安装、Mod / 资源包 / 光影 / 存档 / 截图管理、实例与迁移、
                正版登录、皮肤、新闻、整合包、服务器管理。
              

              

                界面图标中使用的方块贴图版权归 Mojang / Microsoft，仅用于标识版本类型。
